# 试卷手写清除与配图恢复开源方案评估

评估日期：2026-07-22。目标不是“让图片看起来更干净”，而是在不改变题目条件的前提下，恢复可打印的白底印刷内容。

## 结论

整页题干适合 OCR 后重新排版；配图不适合交给通用擦除或生成模型。最终采用：

1. UVDoc 展平整页；
2. OCR 重建题干；
3. 从原图像素提取配图直线、圆、网格和标签位置；
4. 在纯白背景上重新绘制；
5. 用线段像素支撑率、封闭区域数和图邻接关系阻止错误输出。

这条路线没有扩散生成步骤，也没有按题意套用几何模板。恢复图的每条边都必须能追溯到原图像素。

## 方案分析

### HandWritingEraser-Pytorch

- 地址：<https://github.com/AndSonder/HandWritingEraser-Pytorch>
- 原理：DeepLabV3+ 三分类语义分割，将像素分为背景、印刷内容和手写内容。
- 许可证：MIT。
- 优点：任务定义最接近中文试卷；三分类比“前景/背景”二分类更有机会区分黑色铅笔与黑色印刷。
- 限制：预训练权重只通过百度网盘发布，仓库没有稳定自动下载与版本哈希流程；训练数据和字体、笔迹域与当前小奥照片不完全一致。
- 判断：值得作为未来可替换的手写分割候选，但当前不能成为可复现的默认依赖。

### DIS Handwriting Remover

- 地址：<https://github.com/ivanhe123/Handwriting-Removal-DIS>
- 权重：<https://huggingface.co/Inoob/DIS-Handwriting-Remover>
- 原理：把手写擦除改写成 DIS 高分辨率二值分割，再按掩膜把像素置白。
- 优点：源码和权重可自动下载，MPS 推理速度快。
- 实测：在 6 张样例中，主要铅笔笔迹的预测概率接近零；`IMG_9327` 的铅笔椭圆没有被识别。
- 原因：公开训练集由三分类数据转换为“手写前景/其余背景”，对低对比度铅笔和印刷线交叠区域泛化不足。
- 判断：淘汰，不进入最终选择链。

### InkErase

- 地址：<https://huggingface.co/ynyg/InkErase>
- 原理：U-Net++、ResNet50 编码器，直接预测清洁 RGB 图；训练损失组合 Charbonnier、SSIM、边缘损失和掩膜损失。
- 优点：权重公开，图像到图像输出理论上可同时处理笔迹和背景。
- 实测：`IMG_9327` 中误删印刷标签 C、E，保留主要铅笔椭圆；三个圆样例保留手写数字并删除部分印刷字母；背景产生粉红/绿色纹理。
- 原因：图像到图像回归没有显式的“题目条件不可改变”约束，结构边缘损失也无法区分印刷边和手写边。
- 判断：淘汰。模型页许可证元数据为 Apache-2.0，而 README 写 MIT，许可证信息本身也不一致。

### SCUT-EnsExam

- 地址：<https://github.com/SCUT-DLVCLab/SCUT-EnsExam>
- 原理：真实考试卷手写擦除配对数据，545 张，提供带笔迹图、清洁标签和四边形标注。
- 价值：适合训练/验证试卷专用擦除模型。
- 限制：仅限非商业研究，需机构签章、论文证明和人工审批；不能作为工具安装时自动获取的数据依赖。
- 判断：如果后续开展专门训练，可用于离线研究基准；当前实现不依赖它。

### DocWaveDiff

- 地址：<https://github.com/miccunifi/DocWaveDiff>
- 原理：Wavelet U-Net Early Predictor 先恢复，再由扩散 Denoiser Refiner 预测残差；DWT/IWT 分离多尺度频率信息。
- 许可证：MIT。
- 优点：论文任务包含文档去模糊和手写移除，频率分解适合保留细线。
- 限制：仓库只给训练代码和配置，没有公开可直接复现的手写移除权重；扩散细化存在生成不存在结构的风险。
- 判断：不能作为当前可复现实现，也不能直接通过配图事实一致性门禁。

### LaMa / IOPaint

- 地址：<https://github.com/Sanster/IOPaint>
- 原理：给定准确掩膜后，用大感受野 inpainting 网络补背景。
- 优点：对纸张背景补洞效果优于传统 Telea。
- 限制：它解决“怎么填洞”，不解决“哪些像素是手写”；错误掩膜会直接擦除印刷文字或公共边。
- 判断：只有在独立手写掩膜已可靠时才可作为局部后处理，不能承担识别职责。

### VTracer / Potrace

- 地址：<https://github.com/visioncortex/vtracer>、<https://potrace.sourceforge.net/>
- 原理：将二值或彩色位图轮廓转换为矢量路径。
- 优点：输出清晰、可缩放。
- 限制：会同样忠实向量化铅笔圈、答案和印刷线，不能判断有效内容。
- 判断：可作为最后的格式转换，不是清除算法。

### OpenCV 几何提取

- 文档：<https://docs.opencv.org/4.x/>
- 原理：
  - 长条形态学开运算提取水平/竖直结构；
  - HoughLinesP 补充被局部遮挡的线段；
  - HoughCircles 从梯度投票恢复圆心和半径；
  - connectedComponents 计算封闭区域；
  - distanceTransform 测量恢复线与原图印刷墨迹的距离。
- 优点：完全由输入像素决定、可解释、无生成幻觉；线段、圆和网格特别适合此方法。
- 限制：只适合可参数化图形，复杂插图仍应进入人工确认。
- 判断：作为当前配图恢复的主方案。

## 当前质量门禁

- 地图：至少 5 条水平线、3 条竖线；线段像素支撑率不低于 0.82；封闭区域数等于题干国家数；标签最多只允许一个满足唯一性条件的漏识别补位；邻接关系从公共边计算。
- 三圆图：必须检测到 3 个相近半径圆，恢复后必须恰好形成 7 个封闭区域；圆周像素支撑率不低于 0.62。
- 2×10 网格：必须检测/拟合出 3 条水平线和 11 条竖线；线段支撑率不低于 0.82；单元格内部全部清空。
- 所有配图：输出背景固定为纯白，不复制纸张纹理；非结构墨迹像素为零；门禁失败时停止自动输出，不再回退到带笔记截图。
