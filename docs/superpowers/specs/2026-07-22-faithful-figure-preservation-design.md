# 配图原图像素驱动恢复设计

## 原则

原始配图是题目条件的唯一事实来源。系统不得根据题意自行生成替代配图。

## 流程

1. 在展平图中定位题干下方的配图区域，并保存原始裁剪作为审计证据。
2. 直线图使用形态学与 Hough/LSD 从原图提取真实线段；圆图使用 Hough 圆提取真实圆心和半径；网格使用等间距约束补全被笔迹短暂遮挡的线段。
3. 只允许重建在原图中有足够像素支撑的几何结构，禁止依据题意套用预设模板。
4. 地图标签必须由局部 OCR 定位；最多允许一个漏识别标签在“题干标签集合只缺一个、封闭区域也只缺一个”时补入。国家邻接关系必须从恢复图的公共边重新计算。
5. 输出在纯白背景上重新绘制，非结构墨迹全部舍弃，不保留纸张色温、阴影、纹理和手写笔迹。
6. 几何、区域数、标签、像素支撑或邻接校验不通过时停止自动输出并进入人工确认，禁止回退到带笔记原图。

## 开源组件

- UVDoc：整页展平。
- OpenCV morphology、HoughLinesP、HoughCircles：从原始像素提取直线、网格和圆。
- macOS Vision OCR：地图标签的局部定位。
- OpenCV connected components、distanceTransform：封闭区域、公共边和线段像素支撑校验。
- Pillow：在纯白背景上进行抗锯齿矢量绘制。

## 已排除方案

- DIS Handwriting Remover：在样例上手写掩膜覆盖率过低，无法识别主要铅笔圈画。
- InkErase（U-Net++/ResNet50）：实测会误删地图印刷标签 C、E，保留主要铅笔椭圆，并生成明显背景纹理。
- LaMa/IOPaint：只负责按掩膜补洞，不能判断黑色铅笔与黑色印刷线；掩膜错了就会删除题目条件。
- DocWaveDiff：源码已公开但没有可直接复现的手写去除权重，扩散细化也不适合作为几何题条件的事实来源。
- VTracer/Potrace：只能向量化已有前景，不能区分手写和印刷内容，因此不能单独解决本问题。
