# 小奥错题集工具设计规格

## 1. 目标

实现一个本地网页工具，批量处理“一张照片一道题”的小奥错题照片：

- 校正旋转、透视、纸面弯曲和不均匀光照；
- 在不破坏印刷文字及配图的前提下，清理可安全识别的红笔和铅笔标注；
- 自动识别题意并动态归纳题目分类；
- 按分类生成适合 A4 单栏打印的错题集 PDF，每题下方预留订正空间；
- 正常题目全自动完成，低置信度题目进入人工确认队列；
- 始终保留原图和中间结果，不以生成结果覆盖源文件。

## 2. 范围

### 第一版包含

- JPG、JPEG、PNG、WebP 图片导入；
- 一张图片对应一道题；
- 本地网页批量上传、任务状态、结果预览和异常确认；
- 原版式优先的图像校正和保守去笔迹；
- 配图保护；
- 本地与云端识别模式切换；
- 动态分类、分类合并和稳定复用；
- A4 PDF 及分类目录。

### 第一版不包含

- 一张图片自动切分多道题；
- 对被笔迹完全覆盖的印刷内容进行生成式重建；
- 移动端应用、账号系统或云端图片存储；
- 自动解题、答案生成和知识讲解；
- 对复杂手绘图进行矢量化重绘。

## 3. 核心原则

1. **内容保真优先**：无法确认安全的笔迹不清除。
2. **版式保留优先**：输出使用校正后的题面图，不重新排版正文。
3. **识别与清理隔离**：OCR 或多模态模型只读取题意并分类，不直接改动题面。
4. **逐级回退**：复杂展平失败时回退到透视校正，再失败则仅做方向校正。
5. **自动为主、异常确认**：只有低置信度任务阻塞最终 PDF。
6. **本地数据优先**：源图、结果及元数据默认保存在本机。
7. **禁止猜测内容**：第一版禁止生成式修复、内容感知补全及文字或图形重建。只允许在确认属于非印刷背景的区域使用邻域背景估计；保护区重叠、来源不确定或低置信度像素必须原样保留。

## 4. 总体架构

系统由本地网页前端和 Python 服务端组成。

### 4.1 网页前端

- 批量导入照片；
- 展示批处理进度与失败原因；
- 展示原图、展平图和清理图；
- 仅对低置信度项目提供确认、重试、保留原结果或排除操作；
- 展示动态分类结果；
- 触发 PDF 导出。

### 4.2 图像预处理服务

负责：

- 读取 EXIF 方向并自动旋转；
- 检测纸张或题目区域；
- 透视矫正；
- 检测文字行弯曲程度并按需执行曲面展平；
- 去除阴影、校正白平衡和背景亮度；
- 输出质量指标及置信度。

曲面展平是可插拔步骤。检测到文字基线归一化均方曲率大于 `0.003`，或上下纸边相对页面宽度的弯曲幅度大于 `1.5%` 时触发。展平实现必须遵循统一的“输入图片、输出图片、几何映射、质量指标”接口；单张处理默认限制为 30 秒和 2 GiB 内存。模型不可用、超时或验收指标不达标时使用透视校正结果；若原图弯曲程度已超过触发阈值，则同时进入异常确认队列。

### 4.3 安全去笔迹服务

负责：

- 在 HSV/Lab 等颜色空间检测红笔；
- 结合颜色、纹理、线宽及局部对比度检测铅笔候选；
- 建立印刷文字、印刷线条及配图保护掩膜；
- 仅在候选像素与膨胀后的保护掩膜完全不重叠、周围被确认是空白纸面时，以局部稳健背景颜色估计替换候选像素；
- 对存在冲突的区域保留原像素；
- 输出去笔迹掩膜、清理结果及保真度指标。

保护优先级始终高于清理候选，保护对象依次包括印刷文字和数字、印刷线条、几何图形、配图及浅色印刷。无法区分浅色印刷和铅笔时一律保留。第一版不得调用生成式模型、OpenCV 内容感知修补或其他可能合成文字和图形结构的修复算法。

### 4.4 识别与归类服务

定义统一识别接口，支持：

- 云端多模态 API；
- 本地 OCR/视觉模型；
- 无可用识别器时将任务标记为待处理。

识别器固定从 `normalized` 产物读取题号、题干摘要、知识点描述及候选类别；该产物已校正并去阴影，但尚未去笔迹。识别与去笔迹从 `normalized` 分叉并行执行，分类不依赖 `cleaned` 产物。分类器将知识点与已有动态分类进行语义匹配；匹配不足时创建新分类。人工合并或改名后的分类会成为后续任务的参考。

### 4.5 PDF 服务

负责：

- 按动态分类排序；
- 生成分类目录；
- 使用 210 mm × 297 mm 的 A4 页面、四边 15 mm 页边距和 180 mm 内容宽度；
- 题面等比例缩放，默认不放大，必要时最大放大至 150%，不得裁切；
- 目标有效分辨率为 300 DPI，最低为 180 DPI，低于最低值进入异常确认；
- 每题下方至少预留 45 mm 订正空间；
- 题面与订正区无法同页时，优先在检测到的水平空白带处分割题面，订正区只放在题面最后一段之后；
- 无安全分割位置时，将整题缩放到单页并保留 45 mm 订正区；若有效分辨率因此低于 180 DPI，则进入异常确认，由用户选择接受较低 DPI、指定分页位置或排除该题；
- 嵌入支持中文的字体；
- 通过最终排版后的第二遍渲染生成稳定目录页码；
- 导出前检查页面物理尺寸、图片分辨率和越界情况。打印说明使用“按实际大小/100% 打印且关闭适应页面”，因为 PDF 页面本身已经是 A4。

## 5. 数据流

处理阶段 `processing_stage` 依次为：

1. `imported`：源文件已导入并计算内容哈希；
2. `oriented`：方向已校正；
3. `rectified`：纸面边界和透视已校正；
4. `dewarped`：按需完成曲面展平；
5. `normalized`：阴影和背景已归一；
6. 从 `normalized` 分叉为 `cleaned` 和 `recognized`；
7. `recognized` 完成后进入 `classified`；
8. 清理和分类均完成后结束处理流水线。

状态不能只用一个线性枚举表达。每题另外保存：

- `quality_status`：`pass`、`review` 或 `failed`；
- `review_status`：`not_required`、`pending`、`accepted` 或 `excluded`；
- `recognition_status`：`pending`、`succeeded` 或 `failed`；
- `classification_status`：`pending`、`succeeded` 或 `failed`；
- `selected_artifact_id`：PDF 实际使用的题面产物。

当所有图像质量门槛通过时，系统自动选择 `cleaned` 作为 `selected_artifact_id`；如果没有安全可清理区域，则自动选择 `normalized`。自动选择不得绕过识别和分类状态检查。

每个阶段保存输入、输出、参数、耗时、置信度和错误信息，方便重试及回退。

## 6. 质量门槛与人工确认

默认质量门槛如下，阈值写入带版本的配置，可在固定样例标注完成后调整：

- 方向：方向分类置信度至少 `0.80`，否则进入确认；
- 页面边界：边界检测置信度至少 `0.85`，且矫正后保留原内容掩膜至少 `99.5%`；
- 曲面展平：文字基线均方曲率相对透视结果至少改善 `20%`，内容保留率不得下降超过 `0.5%`；
- 背景归一：空白区亮度变异系数至少降低 `20%`，同时保护区中位色差 `ΔE00` 不得超过 `3`；
- 去笔迹：最终清理掩膜与膨胀保护区的交集必须为 `0` 像素；保护区结构相似度 `SSIM` 至少为 `0.995`，保护区变化像素占比不超过 `0.1%`；
- OCR：平均字符置信度至少 `0.75`，且有效汉字或数字不少于 `8` 个；
- 分类：输出必须通过结构校验；主分类名称为 2 至 12 个汉字；归入已有分类的语义相似度至少 `0.82`，新建分类的模型置信度至少 `0.75`；
- 异常队列：固定样例中所有会导致文字、数字或配图损坏的结果必须 `100%` 进入确认队列；正常样例误入确认队列的比例不得高于 `30%`。

指标统一按以下定义计算：

- 所有几何坐标先除以图片宽、高归一化到 `[0,1]`；几何映射必须随 `Artifact` 保存；
- 文字基线来自二值化连通域与 OCR 行框的交集，每行使用三次多项式 `y=f(x)` 拟合，行曲率为采样点上 `f''(x)` 的均方根，图片曲率取至少 3 条有效文字行的中位数；不足 3 行时该指标不可测，若纸边指标已触发展平则进入确认，否则跳过展平；
- 原内容掩膜是文字/数字、印刷连通域、线条和配图检测结果的并集，在 300 DPI 等效尺度下向外膨胀 3 像素；内容保留率为经几何映射后仍落在输出有效区域内的原内容掩膜像素数除以原内容掩膜像素总数；
- 空白区是纸张掩膜减去保护区、标注候选区及其 5 mm 膨胀区；背景亮度变异系数使用 64×64 像素网格内 `L*` 中位数的标准差除以均值；空白区少于纸张面积的 `10%` 时指标不可测并进入确认；
- 色差和 SSIM 比较均先通过保存的几何映射对齐输入与输出；变化像素定义为 `ΔE00 > 2` 的像素；聚合范围固定为保护区；
- OCR 平均置信度按字符数加权；没有字符级置信度的识别器不得让题目自动通过；
- 已有分类匹配分数使用版本固定的嵌入模型余弦相似度；新分类置信度使用在冻结标注集上完成温度缩放后的分类器概率，未校准的 provider 不得让新分类自动通过；
- 任一指标无可测区域、缺少依赖数据或出现非有限数值时，按未通过处理，不得使用默认高分。

`Sample` 固定集需要为方向、纸张边界、内容区域、保护区域、可安全清理区域、损坏风险、题干转写及主分类建立人工标注。样例哈希、标注版本、指标实现版本和阈值版本必须一同冻结，验收报告逐项输出原始测量值。

任一硬性门槛未通过时，`quality_status=review`、`review_status=pending`，并记录触发指标、阈值和候选回退产物。处理异常且没有可用回退产物时使用 `quality_status=failed`。

确认页面允许：

- 使用当前结果；
- 回退到上一个处理阶段；
- 使用更保守的清理强度重试；
- 保留原标注；
- 重新运行识别；
- 人工指定分类，或明确归入“未分类”；
- 将该题排除出本次 PDF。

“使用当前结果”将当前候选写入 `selected_artifact_id` 并设置 `review_status=accepted`；“保留原标注”选择 `normalized` 产物；“回退”选择最近一个通过门槛的产物；“排除”设置 `review_status=excluded`。图片审核不能自动解决识别或分类失败；此时必须重新识别、人工指定分类，或由用户明确归入具有固定 UUID 的“未分类”。不要求用户逐题确认正常结果。

## 7. 动态分类

每题保存：

- 识别出的题号和题干摘要；
- 一个主要知识点；
- 若干辅助标签；
- 分类置信度；
- 分类来源和模型信息。

分类库的作用域是当前本地项目。分类使用不可变 UUID，名称和描述可修改；识别记录同时保存识别模型、提示词、嵌入模型和阈值配置的版本，以便复现和重新归类。

分类流程：

1. 模型生成短而稳定的知识点描述；
2. 与现有分类名称、描述及代表题目计算语义相似度；
3. 高于阈值时归入已有分类；
4. 低于阈值时由模型生成新分类名称；
5. 对近似分类生成合并建议，但不自动改变已有题目的分类；
6. 人工确认合并后保留旧分类别名、变更历史和可回滚映射；
7. 人工合并或改名后更新后续分类参考。

分类名称不直接使用模型的长句，需规范为适合目录展示的短名称。分类发生变化后可重新生成 PDF，但不重复执行图像处理。

## 8. 数据模型

核心实体：

- `Batch`：一次导入及导出任务；
- `Problem`：一道题、各维度状态和选中产物；
- `Artifact`：各处理阶段生成的图片、掩膜和指标；
- `Recognition`：题意、知识点、置信度、模型及提示词版本；
- `Category`：不可变 ID、可变名称、描述、别名、版本和代表样本；
- `ProblemCategory`：题目与分类关系；
- `Export`：PDF 参数、文件路径和生成状态。

元数据使用 SQLite；图片和 PDF 使用本地文件目录存储。源图通过内容哈希去重。

## 9. 失败与回退

- 单题失败不终止整批任务；
- 曲面展平失败时使用透视校正结果；
- 透视校正失败时使用方向校正结果；
- 去笔迹质量不足时选择 `normalized` 未清理版本并进入确认；
- 当前识别器失败时只按配置重试同一识别器，不自动切换到其他本地模型、云端服务或云端区域；
- 无识别结果时进入异常确认队列，不猜测题型；
- 默认只有当批次中的题目全部处于“可导出”或 `excluded` 时才能生成最终 PDF；
- 用户可显式选择“部分导出”，此时跳过所有 `pending` 或 `failed` 题目，并在导出摘要中列出跳过项；
- “可导出”要求 `selected_artifact_id` 非空、图片质量通过或 `review_status=accepted`、`recognition_status=succeeded` 且 `classification_status=succeeded`；归入“未分类”视为一次显式成功分类；
- PDF 只包含满足“可导出”条件的题目。

## 10. 安全与隐私

- 默认不上传图片；本地模式必须零网络访问，并由测试拦截外部连接验证；
- 首次启用每个云端识别器前，界面必须明确展示服务商、处理区域、上传内容、服务商留存策略和删除策略，并取得单独授权；
- 云端只上传去除 EXIF 和文件名的 `normalized` 题目裁切图，不上传源照片、清理产物或其他批次数据；
- 请求设置超时且不在本地缓存请求体；服务商是否支持服务端零留存由配置明确标注，无法确认时提示用户可能留存；
- 从本地切换到云端、从一个云端服务商切换到另一个服务商，或切换处理区域时必须重新确认，失败时不得静默改投其他服务；
- API 密钥通过环境变量或本地密钥配置读取，不写入数据库、日志或前端；
- 日志不记录完整识别请求和图片二进制；
- 导入文件名进行规范化，禁止目录穿越；
- 对图片尺寸、数量和文件大小设置上限，避免资源耗尽。

本地服务默认只监听 loopback 地址。服务端校验 `Host` 和 `Origin`，拒绝非本机 Host、未知 Origin 及跨源写请求；启动时生成随机会话令牌，上传、处理、导出和云端授权等写操作必须携带该令牌。监听局域网或公网地址必须由用户显式启用，并在启动前展示数据暴露风险。

## 11. 验收与测试

以 `Sample` 目录中的图片建立固定测试集，并覆盖已提供的旋转、纸面弯曲、手写标注和配图场景。

### 自动测试

- EXIF 和常见旋转方向；
- 页面边界置信度、内容保留率及透视变换；
- 曲面展平的触发条件、文字行曲率改善和资源限制回退；
- 阴影归一前后的背景均匀度及保护区色差；
- 红笔、铅笔候选掩膜及非印刷背景约束；
- 文字与配图保护区的零交集、SSIM 和变化像素比例；
- 禁止生成式修复的依赖与调用回归；
- 阶段回退和单题失败隔离；
- 多维状态迁移和人工确认操作；
- 动态分类匹配、创建、合并建议、历史及版本复现；
- A4 页面尺寸、15 mm 边距、最低 DPI、订正区、长题安全分页、无安全分页点回退、目录页码、中文字体和图片越界；
- API 失败、本地零网络、云端授权和无识别器模式；
- loopback 监听、Host/Origin 校验、会话令牌及显式非本机监听。

### 样例验收

- 题面方向正确且四边整齐；
- 弯曲文字行满足默认曲率改善阈值，内容保留率满足门槛；
- 印刷文字、数字、圆圈、线段及原题配图保持可读；
- 明确位于空白背景上的标注被清除；
- 与印刷内容重叠或低置信度的标注被保留；
- 正常题目无需人工操作即可完成；
- 所有可能损坏印刷内容的异常题目均进入确认队列；
- 分类目录可读，近似类别不会大量重复创建；
- PDF 页面本身为 A4，可按“实际大小/100%”打印且无需适应页面缩放。

## 12. 建议技术栈

- 服务端：Python 3.12、FastAPI；
- 图像处理：OpenCV、Pillow、NumPy；
- 曲面展平：基础几何方案加可插拔文档展平模型；
- OCR：PaddleOCR 或可插拔本地识别器；
- 云端识别：统一 provider 接口；
- 数据库：SQLite、SQLAlchemy；
- PDF：HTML/CSS 模板与 Chromium 打印；
- 前端：轻量 TypeScript 页面；避免在第一版引入复杂状态框架；
- 测试：pytest、图像质量指标、固定样例回归和 PDF 结构检查。

## 13. 第一版完成标准

用户能够启动本地服务，将 `Sample` 目录或浏览器中选中的图片批量导入；系统自动完成题面校正、保守去笔迹、题意识别及动态分类。正常任务可直接生成带目录和订正空间的 A4 PDF，低置信度任务会集中进入确认队列，原图及所有处理阶段均可追溯。
