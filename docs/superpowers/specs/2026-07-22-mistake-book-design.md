# 小奥错题集工具设计规格

## 1. 目标

实现一个本地网页工具，批量处理“一张照片一道题”的小奥错题照片：

- 校正旋转、透视、纸面弯曲和不均匀光照；
- 在不破坏印刷文字及配图的前提下，清理可安全识别的红笔和铅笔标注；
- 自动识别题意并动态归纳题目分类；
- 按分类生成适合 A4 单栏打印的错题集 PDF，每题下方预留订正空间；
- 正常题目全自动完成，低置信度题目进入人工确认队列；
- 始终保留原图和中间结果，不以生成结果覆盖源文件。

## 2. 范围

### 第一版包含

- JPG、JPEG、PNG、WebP 图片导入；
- 一张图片对应一道题；
- 本地网页批量上传、任务状态、结果预览和异常确认；
- 原版式优先的图像校正和保守去笔迹；
- 配图保护；
- 本地与云端识别模式切换；
- 动态分类、分类合并和稳定复用；
- A4 PDF 及分类目录。

### 第一版不包含

- 一张图片自动切分多道题；
- 对被笔迹完全覆盖的印刷内容进行生成式重建；
- 移动端应用、账号系统或云端图片存储；
- 自动解题、答案生成和知识讲解；
- 对复杂手绘图进行矢量化重绘。

## 3. 核心原则

1. **内容保真优先**：无法确认安全的笔迹不清除。
2. **版式保留优先**：输出使用校正后的题面图，不重新排版正文。
3. **识别与清理隔离**：OCR 或多模态模型只读取题意并分类，不直接改动题面。
4. **逐级回退**：复杂展平失败时回退到透视校正，再失败则仅做方向校正。
5. **自动为主、异常确认**：只有低置信度任务阻塞最终 PDF。
6. **本地数据优先**：源图、结果及元数据默认保存在本机。

## 4. 总体架构

系统由本地网页前端和 Python 服务端组成。

### 4.1 网页前端

- 批量导入照片；
- 展示批处理进度与失败原因；
- 展示原图、展平图和清理图；
- 仅对低置信度项目提供确认、重试、保留原结果或排除操作；
- 展示动态分类结果；
- 触发 PDF 导出。

### 4.2 图像预处理服务

负责：

- 读取 EXIF 方向并自动旋转；
- 检测纸张或题目区域；
- 透视矫正；
- 检测文字行弯曲程度并按需执行曲面展平；
- 去除阴影、校正白平衡和背景亮度；
- 输出质量指标及置信度。

### 4.3 安全去笔迹服务

负责：

- 在 HSV/Lab 等颜色空间检测红笔；
- 结合颜色、纹理、线宽及局部对比度检测铅笔候选；
- 建立印刷文字、印刷线条及配图保护掩膜；
- 仅修补与保护掩膜不冲突且置信度足够高的标注区域；
- 对存在冲突的区域保留原像素；
- 输出去笔迹掩膜、清理结果及保真度指标。

### 4.4 识别与归类服务

定义统一识别接口，支持：

- 云端多模态 API；
- 本地 OCR/视觉模型；
- 无可用识别器时将任务标记为待处理。

识别器从“已展平但未去笔迹”的图片读取题号、题干摘要、知识点描述及候选类别。分类器将知识点与已有动态分类进行语义匹配；匹配不足时创建新分类。人工合并或改名后的分类会成为后续任务的参考。

### 4.5 PDF 服务

负责：

- 按动态分类排序；
- 生成分类目录；
- A4 单栏排版；
- 等比例缩放题面，避免裁切；
- 在每题下方预留可配置订正空间；
- 嵌入支持中文的字体；
- 导出前检查页面尺寸、图片分辨率和越界情况。

## 5. 数据流

每张图片依次经历以下状态：

1. `imported`：源文件已导入并计算内容哈希；
2. `oriented`：方向已校正；
3. `rectified`：纸面边界和透视已校正；
4. `dewarped`：按需完成曲面展平；
5. `normalized`：阴影和背景已归一；
6. `cleaned`：安全笔迹区域已修补；
7. `recognized`：题意和知识点已提取；
8. `classified`：已匹配或创建动态分类；
9. `ready`：质量门槛通过，可进入 PDF；
10. `needs_review`：任一关键质量门槛未通过，等待确认。

每个阶段保存输入、输出、参数、耗时、置信度和错误信息，方便重试及回退。

## 6. 质量门槛与人工确认

以下情况进入异常确认队列：

- 未可靠检测到纸张或题目边界；
- 曲面展平后文字行畸变加重；
- 展平结果疑似裁掉正文或配图；
- 清理掩膜与印刷内容保护区冲突过多；
- 清理前后结构差异超过保真阈值；
- 识别结果为空或置信度不足；
- 分类结果无法稳定归入已有或新建类别。

确认页面允许：

- 使用当前结果；
- 回退到上一个处理阶段；
- 使用更保守的清理强度重试；
- 保留原标注；
- 将该题排除出本次 PDF。

不要求用户逐题确认正常结果。

## 7. 动态分类

每题保存：

- 识别出的题号和题干摘要；
- 一个主要知识点；
- 若干辅助标签；
- 分类置信度；
- 分类来源和模型信息。

分类流程：

1. 模型生成短而稳定的知识点描述；
2. 与现有分类名称、描述及代表题目计算语义相似度；
3. 高于阈值时归入已有分类；
4. 低于阈值时由模型生成新分类名称；
5. 对近似新分类执行自动合并检查；
6. 人工合并或改名后更新分类规则。

分类名称不直接使用模型的长句，需规范为适合目录展示的短名称。分类发生变化后可重新生成 PDF，但不重复执行图像处理。

## 8. 数据模型

核心实体：

- `Batch`：一次导入及导出任务；
- `Problem`：一道题及其当前状态；
- `Artifact`：各处理阶段生成的图片、掩膜和指标；
- `Recognition`：题意、知识点、置信度和模型信息；
- `Category`：动态分类名称、描述和代表样本；
- `ProblemCategory`：题目与分类关系；
- `Export`：PDF 参数、文件路径和生成状态。

元数据使用 SQLite；图片和 PDF 使用本地文件目录存储。源图通过内容哈希去重。

## 9. 失败与回退

- 单题失败不终止整批任务；
- 曲面展平失败时使用透视校正结果；
- 透视校正失败时使用方向校正结果；
- 去笔迹质量不足时保留未清理版本；
- 云端识别失败时按配置重试，并可切换本地识别；
- 无识别结果时进入异常确认队列，不猜测题型；
- PDF 仅包含 `ready` 或已人工确认的题目。

## 10. 安全与隐私

- 默认不上传图片，只有选择云端识别器时才向配置的服务发送图片；
- API 密钥通过环境变量或本地密钥配置读取，不写入数据库、日志或前端；
- 日志不记录完整识别请求和图片二进制；
- 导入文件名进行规范化，禁止目录穿越；
- 对图片尺寸、数量和文件大小设置上限，避免资源耗尽。

## 11. 验收与测试

以 `Sample` 目录中的图片建立固定测试集，并覆盖已提供的旋转、纸面弯曲、手写标注和配图场景。

### 自动测试

- EXIF 和常见旋转方向；
- 页面边界及透视变换；
- 曲面展平的文字行直线度变化；
- 阴影归一前后的背景均匀度；
- 红笔、铅笔候选掩膜；
- 文字与配图保护区；
- 阶段回退和单题失败隔离；
- 动态分类匹配、创建和合并；
- A4 页面尺寸、边距、中文字体和图片越界；
- API 失败、本地模式和无识别器模式。

### 样例验收

- 题面方向正确且四边整齐；
- 弯曲文字行得到明显改善，不能因展平裁掉内容；
- 印刷文字、数字、圆圈、线段及原题配图保持可读；
- 明确位于空白背景上的标注被清除；
- 与印刷内容重叠或低置信度的标注被保留；
- 正常题目无需人工操作即可完成；
- 异常题目准确进入确认队列；
- 分类目录可读，近似类别不会大量重复创建；
- PDF 可在 A4 纸上按 100% 比例正常打印。

## 12. 建议技术栈

- 服务端：Python 3.12、FastAPI；
- 图像处理：OpenCV、Pillow、NumPy；
- 曲面展平：基础几何方案加可插拔文档展平模型；
- OCR：PaddleOCR 或可插拔本地识别器；
- 云端识别：统一 provider 接口；
- 数据库：SQLite、SQLAlchemy；
- PDF：HTML/CSS 模板与 Chromium 打印；
- 前端：轻量 TypeScript 页面；避免在第一版引入复杂状态框架；
- 测试：pytest、图像质量指标、固定样例回归和 PDF 结构检查。

## 13. 第一版完成标准

用户能够启动本地服务，将 `Sample` 目录或浏览器中选中的图片批量导入；系统自动完成题面校正、保守去笔迹、题意识别及动态分类。正常任务可直接生成带目录和订正空间的 A4 PDF，低置信度任务会集中进入确认队列，原图及所有处理阶段均可追溯。
